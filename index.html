How the Builder Thinks

Simple + store-friendly
Primary goal: everyone gets the same number of games and your schedule stays sane.
  • Round Robin only when it actually fits (players − 1 rounds).
  • Swiss is the default for 6–16 when time is limited.
  • Swiss + Top Cut only when you have an extra round’s worth of time.
  • Odd players → Bye (counts as a win; VP editable).
If you want “do all of it” flexibility, this is it: build a recommended structure, then you can still override rounds/scoring, lock/unlock rounds, or manually pair.
